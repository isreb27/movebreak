# Code of conduct

Movebreak follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and focus on what is best for
the people who use and build this project. Harassment of any kind is not accepted.

To report unacceptable behaviour, contact the maintainer privately through
[GitHub](https://github.com/isreb27). Reports are handled confidentially.
